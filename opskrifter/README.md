# Min Kogebog

Opskriftsapp til mobilen.

- **Indsæt fra nettet**: kopiér en opskrift fra en hjemmeside og sæt den ind. Den ensrettes til samme format (amerikanske mål omregnes til dl, g, spsk og tsk).
- **Skriv selv**: én ingrediens pr. linje, mængden først.
- **Skalér**: vælg hvor mange du laver mad til, så regnes alle mængder om (fx 1000 g bliver til 1 kg).
- Afkryds ingredienser og trin mens du laver mad, og hold skærmen tændt.

`app.html` er kilden. `./build.sh` laver `index.html`, som kan åbnes i en browser og føjes til hjemmeskærmen.
I den selvstændige version gemmes opskrifter på enheden; på claude.ai gemmes de på din konto, og Claude kan ensrette indsat tekst og skærmbilleder.
